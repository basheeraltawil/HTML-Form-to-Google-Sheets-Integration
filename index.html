HTML Form to Google Sheets Integration

A Complete Guide to Connecting Your Web Forms with Google Sheets Using Google Apps Script

How It Works: The Data Flow

HTML Form
(Your Website)
↓
Google Apps Script
(Bridge/API)
↓
Google Sheets
(Database)

This method creates a secure bridge between your HTML form and Google Sheets without exposing sensitive data.

1

Set Up Google Sheet

Create your data structure with proper headers that match your form field names.

Sheet Headers Example:

Timestamp | Name | Email | Message | Product

Why This Matters:

  • Headers must match form field names
  • First row is reserved for headers
  • Data starts from second row
2

Create Google Apps Script

This script acts as the bridge between your form and the spreadsheet.

Basic Script Code:

// Configuration const SHEET_NAME = 'Sheet1'; const scriptProp = PropertiesService.getScriptProperties(); function doPost(e) { const sheet = SpreadsheetApp.openById( scriptProp.getProperty('key') ).getSheetByName(SHEET_NAME); const headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]; const newRow = headers.map(header => header === 'Timestamp' ? new Date() : e.parameter[header] ); sheet.appendRow(newRow); return ContentService.createTextOutput( JSON.stringify({ result: 'success' }) ).setMimeType(ContentService.MimeType.JSON); }
3

Deploy as Web App

Make your script accessible to the web with proper permissions.

Deployment Settings:

  • Execute as: Me
  • Who has access: Anyone
  • Description: Form Handler

Important Notes:

  • Copy the Web App URL
  • You'll need this in your HTML form
  • Test the deployment
4

Create HTML Form

Build your form with proper field names and JavaScript handling.

Form Structure:

<form id="contactForm"> <input name="Name" type="text" required> <input name="Email" type="email" required> <textarea name="Message"></textarea> <button type="submit">Send</button> </form>

Field Names Must Match:

  • HTML: name="Email"
  • Sheet: Email (header)
5

JavaScript Integration

Connect your form to the Google Apps Script using Fetch API.

Submission Handler:

const form = document.getElementById('contactForm'); const scriptURL = 'YOUR_SCRIPT_URL_HERE'; form.addEventListener('submit', e => { e.preventDefault(); fetch(scriptURL, { method: 'POST', body: new FormData(form) }) .then(response => response.json()) .then(data => { alert('Success! Data saved to sheet.'); form.reset(); }) .catch(error => { alert('Error! Please try again.'); }); });
6

Security & Best Practices

Protect your data and ensure reliable form submissions.

Security Measures:

  • Input validation in both form and script
  • Rate limiting in Apps Script
  • Error handling and user feedback

Best Practices:

  • Test thoroughly before deployment
  • Use loading states for better UX
  • Implement form validation
  • Keep script URL secure

Troubleshooting Common Issues

❌ Data Not Saving to Sheet

  • Check field names: HTML field names must match sheet headers exactly
  • Verify script deployment: Ensure Web App is deployed with "Anyone" access
  • Check script permissions: Run initialSetup function to grant permissions

❌ CORS Errors

  • Google Apps Script handles CORS automatically
  • If using custom domains, check script permissions
  • Ensure you're using POST method, not GET

❌ Script URL Issues

  • Copy the entire Web App URL from deployment
  • URL should end with /exec
  • Test the URL directly in browser (should show error about GET method)
